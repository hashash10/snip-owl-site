SUPPORT

Get back to capturing.

Start with these quick checks for the most common capture, recording, and sync issues.

The panel shows the wrong tab

Close the panel, select the page you want to capture, and open Snip Owl again from the extension icon. The extension reads the active tab when it opens.

The record button is out of view

Scroll inside the Snip Owl panel. If Chrome’s toolbar overlaps the panel, close and reopen it after the page has fully loaded. The capture controls are designed to remain inside the page viewport.

A capture is missing on another device

Confirm that both devices use the same Google account. A signed-in capture uploads to the private backend by default. If the device was offline, it remains in the browser queue and retries after connectivity returns. Open the library again after a short wait.

Google sign-in does not finish

Allow pop-ups for the Snip Owl site, make sure third-party sign-in is permitted, and retry. If you are using a preview build, your Google account may also need to be included in the current test group.

Delete a capture

Open the capture in the web library and choose Delete. This removes the cloud record and stored media. Temporary browser copies are removed automatically after the backend verifies their upload.

Before reporting a problem

  • Record the Chrome version and operating system.
  • Note whether the issue affects screenshots, recordings, or both.
  • Include the page where it happened, unless the URL is sensitive.
  • Describe what you expected and what appeared instead.
